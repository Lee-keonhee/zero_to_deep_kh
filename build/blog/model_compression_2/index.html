1. 양자화 기본 개념

양자화란?

  • float32 → int8/int4 등으로 변환
  • 메모리 절약 + 연산 속도 향상
  • 대신 정확도 손실 발생

왜 단순 소수점 자르기는 안 되나?

임의의 범위를 고정된 정수 타입(int8 등)에 맞춰야 하기 때문

양자화 공식:

scale = (max - min) / 255
quantized = round((value - min) / scale)

예시:

가중치 범위: [-127.5, 127.5]
int8 범위: [0, 255]

0.12345 → 128 (int8)
100.6789 → 228 (int8)

전체 범위를 균등하게 정수 범위로 매핑하는 것이 핵심!

2. 양자화 방식

PTQ (Post-Training Quantization)

학습 완료 모델 → 양자화 변환 → 바로 사용

장점:

  • ✅ 빠름
  • ✅ 추가 학습 불필요

단점:

  • ❌ 성능 저하 있을 수 있음

종류:

  1. Static PTQ

    • 활성화 값 범위를 미리 계산해서 고정
    • Calibration dataset으로 scale/zero-point 사전 결정
    • 빠름, 하지만 예상 밖 입력에 부정확할 수 있음

  2. Dynamic PTQ

    • 추론 시마다 활성화 값 범위 계산
    • 매번 scale/zero-point 새로 계산
    • 느림, 하지만 모든 입력에 최적화

QAT (Quantization-Aware Training)

일반 학습 → 양자화 시뮬레이션하며 재학습 → 양자화

프로세스:

# 각 epoch마다:
weight_float = [0.12345, 0.67890, ...]  # 실제 저장 가중치

# 순전파: 양자화 시뮬레이션
weight_quantized = quantize(weight_float)
weight_fake = dequantize(weight_quantized)
output = weight_fake @ input  # 양자화 오차 반영

# 역전파: float 가중치 업데이트
loss.backward()
weight_float -= lr * gradient

특징:

  • 순전파: 양자화된 값으로 계산
  • 역전파: float 가중치 업데이트
  • 결과: 원본과 다른 “양자화에 강한” 새 모델

장점:

  • ✅ 성능 유지

단점:

  • ❌ 학습 시간 증가 (사실상 두 번 학습)

QLoRA (Quantized LoRA)

모델을 4bit로 양자화 → LoRA만 학습

구조:

  • 4bit 베이스 모델 (frozen, 학습 안 함)
  • LoRA 어댑터만 학습 (전체의 0.1-1%)

장점:

  • ✅ 메모리 효율 극대화
  • ✅ 빠른 학습 (업데이트할 파라미터 극소수)
  • ✅ 성능 거의 유지
  • ✅ PTQ + 소량 파인튜닝의 하이브리드

비교 (Llama-7B 기준):

전통 QAT:
- GPU: A100 80GB 필요
- 시간: 수일~수주
- 메모리: 28GB

QLoRA:
- GPU: RTX 3090 24GB 가능
- 시간: 수시간~하루
- 메모리: 8GB (7GB 모델 + 1GB LoRA)

3. PTQ 알고리즘 발전

초기 (단순 PTQ)

Round-to-nearest 방식
→ 빠르지만 정확도 낮음

2022-2023년

GPTQ (GPT Quantization)

  • Optimal Brain Quantizer 기반
  • Hessian 행렬 사용 (2차 미분 정보)
  • 레이어별 순차 양자화
  • 양자화 오차를 다음 가중치로 분산
  • → 전체 오차 최소화

AWQ (Activation-aware Weight Quantization)

  • 활성화 분포를 고려한 양자화
  • GPTQ보다 빠르고 비슷한 성능

성능 비교:

방법 시간 정확도 특징
Round-to-nearest 1분 낮음 기본 PTQ
GPTQ 30분 높음 널리 사용
AWQ 10분 높음 최근 인기
QuIP# 1시간 최고 연구용

2024-2025년 (최신)

주요 발전:

  1. W4A4 (Weight 4bit + Activation 4bit)

    • 기존: W4A16 (가중치만 4bit, 활성화는 16bit)
    • 최신: W4A4 (둘 다 4bit)
    • Block Clustered Quantization (BCQ)로 1% 미만 손실

  2. NVFP4/MXFP4

    • NVIDIA의 새로운 4bit float 포맷
    • 더 세밀한 스케일링 팩터
    • INT4보다 LLM에 적합

  3. 극단적 양자화

    • 2bit 양자화: full precision 대비 3.4% 차이
    • Ternary (3값) 양자화도 실용화
    • ParetoQ, EfficientQAT 등

  4. 특화된 PTQ

    • TFMQ-DM: Diffusion 모델용
    • Reg-PTQ: Object Detection용
    • LUQ: Multimodal LLM용

결과: PTQ만으로도 QAT 수준의 품질 달성 가능!

4. 양자화 포맷

INT4 (Integer 4-bit)

초기 표준 포맷
정수 4bit로 표현
범위: 0~15 또는 -8~7

NF4 (Normal Float 4-bit)

QLoRA 전용 포맷
정규분포에 최적화된 4bit float
LLM 가중치 분포에 적합

NVFP4 / MXFP4

NVIDIA의 최신 4bit float 포맷
PTQ, QAT, QLoRA 모두 사용 가능
하드웨어 친화적
더 정밀한 스케일링

포맷 발전:

INT4 → NF4 (QLoRA) → NVFP4/MXFP4 (범용)
     (2023)            (2024-2025)

5. 실무 선택 가이드

상황별 최적 방법

빠른 배포 필요

PTQ (GPTQ/AWQ) → 바로 사용
- 시간: 수분~수십분
- 품질: 좋음

최고 성능 필요

QAT (처음부터 재학습)
- 시간: 수일~수주
- 품질: 최고

대형 모델 + 제한된 리소스

QLoRA (4bit + LoRA 학습)
- 시간: 수시간~하루
- 품질: 매우 좋음
- 메모리: 최소
→ 가장 효율적이고 실용적

추론만 + 극한 최적화

W4A4 PTQ (최신 알고리즘)
- BCQ, NVFP4 사용
- 메모리/연산 모두 최소화

모델 타입별 권장사항

대형 언어모델 (LLM):

  • 파인튜닝 필요: QLoRA 👍
  • 추론만: GPTQ/AWQ

비전 모델:

  • 경량화: PTQ (Reg-PTQ 등)
  • 고성능: QAT

Diffusion 모델:

  • TFMQ-DM (특화 PTQ)

6. 경량화가 필요한 이유

드론/엣지 디바이스 문제점

통신 지연

온디바이스 추론: 10-50ms
클라우드 전송: 100-500ms

시속 50km 드론 기준:
100ms = 1.4m 이동
→ 장애물 회피 불가능!

통신 불안정

  • 터널, 건물 사이, 산악 지역
  • 신호 끊김 → 추락 위험

대역폭 문제

  • 4K 영상: 초당 수십 MB
  • 드론 수백대 동시 운용 시 네트워크 마비

프라이버시/보안

  • 민감한 영상 외부 전송 위험
  • 군사/감시 드론은 절대 불가

하이브리드 전략

실시간 제어 (드론):
└─ 경량 모델 (88% 정확도)
   └─ 장애물 회피, 비행 제어 (생존 필수)

후처리 (클라우드):
└─ 고성능 모델 (95% 정확도)
   └─ 촬영 영상 분석, 지도 생성 (나중에 해도 됨)

트레이드오프 예시

옵션 1: 고성능 모델 + 클라우드
- 정확도: 95%
- 지연: 200ms
- 통신 끊김 시: 시스템 마비 ❌

옵션 2: 경량 모델 + 온디바이스
- 정확도: 88%
- 지연: 20ms
- 통신 끊김 시: 정상 작동 ✅

결론: 드론이 떨어지는 것보다는 가끔 오판하는 게 낫다!

결론

핵심 요약

  1. 양자화는 필수
    • 대형 모델의 실용적 배포를 위해 필수적
    • 메모리/속도와 정확도의 균형
  2. PTQ의 놀라운 발전
    • 2024-2025년 들어 PTQ만으로도 실용적 수준
    • GPTQ, AWQ, W4A4, NVFP4 등
  3. **QLoRA
    • 대형 모델 파인튜닝의 사실상 표준
    • 효율과 성능의 완벽한 균형
  4. 상황에 맞는 선택
    • 빠른 배포: PTQ
    • 최고 성능: QAT
    • 효율적 학습: QLoRA
    • 극한 최적화: W4A4 PTQ

미래 전망

현재 트렌드:
- 4bit → 2bit, ternary로 이동
- W4A4 → 전체 pipeline 양자화
- 특화된 PTQ 알고리즘 계속 등장
- 하드웨어 지원 확대 (NVFP4 등)

→ 양자화 기술은 계속 발전 중!
