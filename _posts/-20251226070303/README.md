# PostgreSQL 완전 학습 가이드

## 📚 학습 단계

### ✅ 제공된 파일들 (1-6단계)

1. **01_postgresql_basics.md** - PostgreSQL 기초
   - PostgreSQL 소개 및 특징
   - 설치 및 환경 설정
   - 기본 개념
   - psql 명령어 익히기

2. **02_postgresql_database_basics.md** - 데이터베이스 기본 작업
   - 데이터베이스 생성/삭제/관리
   - 사용자 및 권한 관리
   - 테이블 생성 및 데이터 타입
   - 테이블 구조 수정 (ALTER)

3. **03_postgresql_crud.md** - 데이터 조작 (CRUD)
   - INSERT - 데이터 삽입
   - SELECT - 데이터 조회 기초
   - UPDATE - 데이터 수정
   - DELETE - 데이터 삭제

4. **04_postgresql_query_advanced.md** - 데이터 조회 심화
   - WHERE 절과 조건 연산자
   - 정렬 (ORDER BY)과 제한 (LIMIT, OFFSET)
   - 집계 함수
   - GROUP BY와 HAVING
   - 서브쿼리

5. **05_postgresql_relationships.md** - 관계형 데이터베이스
   - 조인 (INNER, LEFT, RIGHT, FULL, CROSS JOIN)
   - SELF JOIN
   - 제약조건 (PRIMARY KEY, FOREIGN KEY, UNIQUE, CHECK, NOT NULL)

6. **06_postgresql_performance.md** - 성능 최적화
   - 인덱스 생성 및 관리
   - 쿼리 실행 계획 (EXPLAIN)
   - 성능 튜닝 기법

### 📝 추가 요청 가능한 단계 (7-10단계)

7-10단계의 상세 내용이 필요하시면 말씀해주세요:

- **7단계: 고급 기능** (뷰, 트랜잭션, 함수, 프로시저, 트리거, CTE, 윈도우 함수)
- **8단계: 특수 데이터 타입** (JSON/JSONB, 배열, UUID, 날짜/시간)
- **9단계: 운영 및 관리** (백업/복구, VACUUM, 파티셔닝, 복제, 모니터링)
- **10단계: 실전 활용** (연결 풀링, 보안, 애플리케이션 연동)
