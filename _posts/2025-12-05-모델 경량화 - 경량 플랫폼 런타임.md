# 경량 플랫폼별 런타임 구성

양자화 되어 저장된 모델을 배포하기 위해선 모델 형식에 맞게 필요한 런타임 환경을 구성해야 합니다.  
  
다음은 양자화 모델에서 주로 많이 사용되는 런타임 환경인 TF-Lite, Onnx, Torchao(Executorch)의 구축방법에 대하여 살펴봅니다


## TF-Lite 런타임  
  
TF-Lite 모델은 기본적으로 tensorflow에 포함된 `lite`모듈을 통해 구축할 수 있지만, 소형 디바이스(엣지 기기)에서는 보다 가벼운 `tflite-runtime` 모듈을 활용하여 `Interpreter`를 불러오고 런타임을 구축할 수 있습니다.  
  
    Interpreter 생성 -> allocate_tensors (텐서 메모리 할당) -> set_tensor (입력 텐서 세팅)  
    -> invoke (추론 실행) -> get_tensor (출력 텐서)
  
**지원 되는 기기**  
- Linux armv7l(예: Raspberry Pi OS 32비트를 실행하는 Raspberry Pi 2, 3, 4 및 Zero 2)  
- Linux aarch64(예: Debian ARM64를 실행하는 Raspberry Pi 3, 4)  
- Linux x86_64  
  
현재 `tflite-runtime`는 `LiteRT`로 변경되어 `ai-edge-litert` 모듈을 설치하여 런타임 환경을 구성하여 줍니다.

```
!pip install ai-edge-litert
```

```python
from ai_edge_litert.interpreter import Interpreter  
import cv2  
import numpy as np  
  
class_names = ['daffodil', 'sunflower', 'tulip', 'water_lily']  
  
# TensorFlow Lite 모델 파일 경로  
model_path = 'model/tensor_flower_dq.tflite'  
  
# TensorFlow Lite 인터프리터 생성 및 모델 로드  
interpreter = Interpreter(model_path=model_path)  
  
# 텐서 메모리 할당  
interpreter.allocate_tensors()  
  
# 모델의 입력 및 출력 텐서 정보 가져오기  
input_details = interpreter.get_input_details()  
output_details = interpreter.get_output_details()  
  
# 입력 및 출력 텐서 정보 출력  
print(input_details)  
print(output_details)  
  
# 예측할 이미지 로드 및 전처리  
img = cv2.imread('model/flower_sample.jpg')  
img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)  
img = cv2.resize(img, (224, 224))  
img = np.array(img, dtype=np.float32)  
img = np.reshape(img, (-1, 224, 224, 3))  
  
# 모델에 입력 데이터 설정  
interpreter.set_tensor(input_details[0]['index'], img) # (입력 인덱스, 입력 데이터)  
  
# 모델 추론 실행  
interpreter.invoke()  
  
# 모델의 출력 데이터(텐서) 가져오기  
output_data = interpreter.get_tensor(output_details[0]['index']) # 출력 인덱스  
  
# 추론값 출력  
pred_ind = np.argmax(output_data[0])  
print(f'predict class: {class_names[pred_ind]}')
```

> int8 정적 양자화는 일반 PC 환경에서는 XNNPACK 문제가 발생할 수 있습니다.


## ONNX 런타임  
  
onnx 모델은 어떤 플랫폼에서든 `onnxruntime` 모듈을 통해 `InferenceSession`를 불러오고 `run`함수로 쉽게 런타임을 구축할 수 있습니다.  
  
    InferenceSession 생성 -> run (입력,추론,출력 동시 실행)
```
!pip install onnxruntime
```

```python
import cv2  
import numpy as np  
  
# 입력 이미지 세팅  
img = cv2.imread('model/flower_sample.jpg')  
img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)  
img = cv2.resize(img, (224, 224))  
img = np.array(img, dtype=np.float32)  
img = np.reshape(img, (1, 224, 224, 3)) # Initial reshape  
  
# 토치 모델 학습과 동일한 정규화 진행  
mean = np.array([0.485, 0.456, 0.406], dtype=np.float32)  
std = np.array([0.229, 0.224, 0.225], dtype=np.float32)  
img = (img / 255.0 - mean) / std  
img = np.transpose(img, (0, 3, 1, 2)) # Transpose to (1, 3, 224, 224)
```

```python
import onnxruntime  
import numpy as np  
  
class_names = ['daffodil', 'sunflower', 'tulip', 'water_lily']  
  
# onnx 모델 경로  
onnx_path = "model/torch_flower.onnx"  
  
# InferenceSession 생성 (기본 CPU)ort_session = onnxruntime.InferenceSession(onnx_path)  
  
# # providers를 제공하여 CUDA 설정 가능  
# onnxruntime.InferenceSession(onnx_path,  
#                              providers=['CUDAExecutionProvider', 'CPUExecutionProvider'])  
  
# 입출력 서명 가져오기  
input_name = ort_session.get_inputs()[0].name  
output_name = ort_session.get_outputs()[0].name  
  
# 서명에 맞게 입력 및 출력 할당  
output_data = ort_session.run([output_name], {input_name: img})[0]  
  
pred_ind = np.argmax(output_data[0])  
print(f'predict class: {class_names[pred_ind]}')
```

## TensorRT 런타임  
  
`tensorrt`로 변환되어 저장된 모델은 `polygraphy` 라이브러리를 활용하면 쉽게 추론 런타임을 구축할 수 있습니다.

```
!pip install colored tensorrt-cu12 polygraphy
```

```python
from polygraphy.backend.common import BytesFromPath  
from polygraphy.backend.trt import EngineFromBytes, TrtRunner  
import numpy as np  
  
class_names = ['daffodil', 'sunflower', 'tulip', 'water_lily']  
  
# 바이트형식 모델 로드  
plan_path = "model/torch_flower.plan"  
load_engine = EngineFromBytes(BytesFromPath(plan_path))  
  
# Runner를 사용하여 추론 환경 준비  
with TrtRunner(load_engine) as runner:  
  
    # 서명과 맵핑하여 추론 실행  
    outputs = runner.infer(feed_dict={"x": img})  
  
    # 출력 확인  
    output_results = outputs['output']  
  
pred_ind = np.argmax(output_results[0])  
print(f'predict class: {class_names[pred_ind]}')
```

## Pytorch ao 런타임  
  
Torchao를 통해 양자화된 모델의 런타임은 파이토치에서 직접 구성하거나, Executorch를 활용하는 방식으로 런타임을 구축할 수 있습니다.  
  
**토치에서 직접 구축**  
- 주로 FX 그래프 형식으로 변환된 양자화 모델이나 Eager방식으로 양자화된 간단한 모델의 런타임 구축  
- 기존과 동일한 convert_fx를 진행한 모델에(켈리브레이션X) state_dict를 입력하는 방식  
  
**Executorch 런타임**  
- PT2E 양자화 모델을 `.pte`로 저장한다음 해당 파일을 실행하는 방식으로 활용  
- 원본 모델을 생성할 필요없이 `Runtime`을 통해 모델을 바로 로드하고 실행 가능

#### Torch에서 state_dict 로드

```python
import torch  
from torch.ao.quantization.quantize_fx import convert_fx, prepare_fx  
from torch.ao.quantization import QConfigMapping, get_default_qconfig  
import torchvision.models as models  
from torch import nn  
  
# 먼저 원본 모델 구조를 로드  
  
class WTCNN(nn.Module):  
    def __init__(self):  
        super(WTCNN, self).__init__()  
        self.model = models.mobilenet_v3_small(  
            weights=models.MobileNet_V3_Small_Weights.IMAGENET1K_V1)  
        print(self.model)  
        nn_feature = self.model.classifier[0].in_features  
        self.model.classifier = nn.Sequential(  
            nn.Dropout(p=0.3),  
            nn.Linear(nn_feature, 4)  
        )  
  
    def forward(self, x):  
        return self.model(x)  
  
# 원본 모델 로드 및 FX 양자화 준비 (구조를 얻기 위함)  
temp_model = WTCNN().eval()  
example = torch.randn(1, 3, 224, 224)  
torch.backends.quantized.engine = "x86"  
qconfig = get_default_qconfig(torch.backends.quantized.engine)  
qmap = QConfigMapping().set_global(qconfig)  
prepared = prepare_fx(temp_model, qmap, example)  
fx_model = convert_fx(prepared)  
  
# 양자화된 state_dict 로드  
save_path_state_dict = 'model/torch_flower_fx_state_dict.pt'  
  
fx_model.load_state_dict(torch.load(save_path_state_dict))  
fx_model.eval()  
  
# 입력 데이터는 텐서 변환 필요  
img_tensor = torch.from_numpy(img)  
  
outputs = fx_model(img_tensor)  
pred_ind = np.argmax(output_data[0])  
print(f'=========predict class: {class_names[pred_ind]} ==========')
```

#### Executorch에서 런타임

```python
from executorch.runtime import Runtime  
import torch  
  
# 런타임 인스턴스 생성  
runtime = Runtime.get()  
  
# .pte 모델 로드  
program = runtime.load_program("model/torch_flower_pt2e.pte")  
# 메소드 로드  
print("Program methods:", program.method_names)  
method = program.load_method("forward")  
  
# 입력 데이터는 텐서 변환 필요  
img_tensor = torch.from_numpy(img)  
  
# 튜플이나 리스트를 입력  
outputs = method.execute([img_tensor])  
pred_ind = np.argmax(output_data[0])  
print(f'predict class: {class_names[pred_ind]}')
```
